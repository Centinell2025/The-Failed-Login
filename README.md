# The Failed Login

Very Easy DFIR Sherlock concept for Hack The Box.

A Linux server shows suspicious SSH login activity. The investigation focuses on identifying the source IP, affected user, and successful login from a small authentication log.

Status: Draft / preparation for HTB submission.
